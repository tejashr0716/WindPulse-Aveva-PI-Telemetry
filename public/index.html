Custom Software Engineering with AVEVA OSIsoft PI System

Explanations and architectural reasoning designed to impress technical evaluators and solution architects.

Q1: "Why would an enterprise build a custom web app via PI Web API rather than just using AVEVA PI Vision?"

Answer: PI Vision is an operational dashboarding tool intended for plant operators, but it lacks customizable micro-frontend capabilities, native integration with proprietary ML/AI control loops (like dynamic wake steering), role-based multi-tenant customer portals, and integration with modern enterprise identity providers (OAuth2/OIDC). By building custom software over the AVEVA PI Web API, we deliver tailored, high-frequency, sub-second telemetry interfaces while bypassing expensive client licensing constraints.

Q2: "Explain the architecture of PI Asset Framework (AF) Templates and how they scale."

Answer: In large fleet operations (like 500 wind turbines), managing individual PI Points is unsustainable. PI AF decouples raw tags from business logic using Element Templates. We define a single WindTurbine_Template with standardized attributes (e.g. %Element%.ActivePower). Any formula references, roll-up analyses, or Event Frame triggers written on the template automatically propagate to all 500 instances across sites and feeders, ensuring enterprise-wide governance.

Q3: "How do you handle PI Web API rate limits and network latency during high-frequency ingestion?"

Answer: Four core architectural strategies:
1. PI WebSockets Channels: Use /piwebapi/channels to establish persistent bidirectional duplex streams, removing HTTP handshake latency.
2. StreamSets & Batch Requests: Use /streamsets/getinterpolated or POST /batch to retrieve 100+ tag values in a single network round-trip.
3. WebID 2.0 Caching: Cache immutable 28-character Base64 WebIDs in Redis to eliminate costly path-to-ID lookup calls.
4. Client-Side Ring Buffering: Feed real-time streams into fixed-size typed array circular buffers (`Float64Array`) to eliminate garbage collection pauses.

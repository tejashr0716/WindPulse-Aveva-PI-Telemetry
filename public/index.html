ARCHITECTURE REFERENCE

AVEVA OSIsoft PI Web API & Asset Framework Integration Concepts

Technical reference mapping software engineering patterns to official AVEVA PI System capabilities.

1. PI Point vs. Asset Framework (AF) Attribute

A PI Point (Tag) is a low-level time-series stream stored in the PI Data Archive. An AF Attribute is an abstraction in the PI Asset Framework that points to a PI Point, formula, or external table. Templates standardize attributes across hundreds of assets (e.g. %Element%.ActivePower), allowing scalable updates.

2. Batching & StreamSets vs. Point-by-Point Polling

Polling individual streams (/streams/{webId}/value) causes high round-trip latency and connection exhaustion. Production implementations use /streamsets/getrecorded or POST /piwebapi/batch to query all turbine attributes in a single round-trip.

3. PI Status & Quality Flags

AVEVA PI streams return flags: Good, Questionable, and Substituted. When a sensor fails or goes into scan-off, Good=false and the value becomes a PI System Digital State string. Production software must check Good==True before computing numeric KPIs like power curves or fleet totals.
